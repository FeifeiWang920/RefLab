MF Reflector 光学原理说明

本文面向希望理解（或参与改进）求解器的使用者与开发者，解释 MF Reflector 从「光源 + 面片网格 + 远场角度」到「可制造 NURBS 反射镜」的完整计算流程。

1. 问题定义

给定：

  • 一个点光源（位置、发光分布 lambertian / isotropic、可选主光轴）；
  • 一个 U×V 的面片网格（每片有自己的宽/高尺寸，整体落在一张抛物面载体上）；
  • 每个面片的远场角度分布（H / V 方向的角度列表，如 -20,20 表示 ±20° 线性扫过）。

要求构造一组互不干涉的自由曲面面片，使得光源发出的光经各面片反射后， 在远场按设定角度分布展开——这与 LucidShape 的 MF（MacroFocal）面片反射器语义一致。

2. 反射定律给出的目标法线

对面片上的每个采样节点 P，入射方向 I = unit(P − S)； 由该节点的网格参数 (u, v) 查出目标远场方向 R(h, v)（角度列表分段插值）。 反射定律要求镜面法线平分 I 与 R 的夹角：

Nreq = unit( R − I )，再翻转至指向光源一侧

由此得到每个节点的目标坡度（斜率场）：

∂z/∂x = −Nx/Nz，　∂z/∂y = −Ny/Nz

实现见 geometry/engine.py 的 _required_normals() 与 _slopes_on_surface()。坡度场计算只依赖 (xs, ys, z, 光源, 目标角度)， 与面片绝对高度无关。

3. 逐面片求解：从坡度场到高度场

核心难点：按反射定律逐点算出的坡度场并不严格可积 （∂²z/∂x∂y 在 x 方向与 y 方向的求值顺序不一致），直接沿路径积分会产生路径相关的褶皱。 MF Reflector 把它转化为一个最小二乘梯度匹配问题：

minz　Σ ( (zj,i+1−zj,i)/Δx − dzxj,i )² + Σ ( (zj+1,i−zj,i)/Δy − dzyj,i )²，　zseed = 定值

即寻找「坡度最贴合反射定律」的光滑高度场。其中：

  • 区间坡度取两端节点坡度的平均（梯形规则），避免向平均角度聚光；
  • 网格边界行/列赋予更高权重（edge_weight），保证远场矩形的轮廓被遵守；
  • 种子点高度固定（Dirichlet 约束），整片高度以此为基准。

该问题组装为稠密线性系统后一次求解。性能优化后，设计矩阵只依赖网格几何， 分解一次即可在迭代中反复使用（见第 7 节）。

3.1 迭代外环

坡度场本身依赖当前高度 z（改变入射角），因此外环按 solver_iterations（默认 5 次）迭代「算坡度 → 重建高度」， 直到高度增量 ≤ solver_tolerance（默认 1e-5 mm）。

3.2 均匀光强模式

默认模式下角度随面片参数线性分布。开启 uniform_intensity 后， 程序按入射通量（距离平方衰减 × 发光分布 × 入射角余弦）做可分离的累积分布映射： 通量大的区域角度被压缩、通量小的区域被拉伸，使远场矩形内光强均匀。 该模式额外运行 5 轮空间逆问题迭代与极值抛光，计算时间约为默认模式的数倍。

4. 全局求解流水线

单个面片的一次完整生成要经过多个 pass，每个 pass 内所有面片并行计算：

  • Pass 1：每个面片独立、绝对地求解（锚定在载体上）；
  • Pass 2：对整个远场投影做一次边缘极值仿射校准（仅范围，不锁内部），补偿可积投影的整体拉伸/平移；
  • Pass 3：计算面片当前的实际反射角，与目标角做差后重新提问（逆问题），默认 1 轮，均匀光强 5 轮；
  • Pass 4（可选）：邻边基线——把相邻面片的共享边曲线取平均后作为边界条件重新求解，使整族面片在共享边处水密（C0）。注意这会轻微牺牲共享边附近的光学精度（两种设计对边缘坡度的要求相反），默认关闭。

5. 缝隙系统

实际灯具中面片之间要有缝隙（避让、散热、外观），MF Reflector 支持三种语义：

模式含义选项
gap面片光学尺寸按「宽/高 − 缝隙」收缩，缝隙处生成 ruled 缝隙面empty（留空）/ surface（生成缝面）
no_gap面片贴合、无缝隙，可选边界生成方式new_border / old_border / average
step_back面片整体沿法向后退 Z 步长同 gap / no_gap

尺寸语义遵循 LucidShape：输入的宽/高包含缝隙——中间面片光学宽度 = 设定值 − 缝隙， 边缘面片 = 设定值 − 缝隙/2，外边界不收缩。见 _shrink_grid()。

6. NURBS 拟合与导出

  • 每个面片的高度场网格拟合为真正的 B 样条曲面（阶数默认 5，可调）， 各子块共享节点矢量以保证跨块的几何连续性；
  • Patch Fit 支持 approximation（近似、保尺寸）与 interpolation（插值）， 多块拟合时可指定 U/V 向块数与连续性（point / tangent）；
  • STEP 导出：全部光学面与缝隙面经 OpenCascade 缝合为单一 Shell， CATIA 收到的是一个连贯实体而非散面；
  • STL / OBJ：对面片网格三角化后导出，用于快速查看或 3D 打印。

7. 性能架构

16×16（256 面片）网格约 3 秒完成生成，关键措施：

  1. 预分解最小二乘：高度重建的系数矩阵只依赖网格几何，与坡度无关。 每个面片只组装/分解一次，迭代中仅做矩阵-向量乘； 早期实现每轮迭代都做一遍 SVD 最小二乘，占总耗时约 77%；
  2. 向量化目标网格：所有目标角查询闭包支持整网格数组输入， 消除每面片每轮数百次 Python 标量调用；
  3. 并行层级：面片之间天然独立，由线程池并行（MF_REFLECTOR_JOBS 可调）； BLAS 内部线程限制为 1——小矩阵场景下 OpenBLAS 多线程只有同步开销， 两层同时并行会互相踩踏；
  4. NURBS 节点搜索用 numba JIT 加速（geometry/nurbs.py）；
  5. 黄金基线守护：tests/test_golden_height_field.py 对 7 组参数矩阵 断言优化前后高度场 max|Δz| < 1e-8 mm——所有性能改动都不允许触碰光学结果。
